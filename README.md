# 数学学习全景图 · mathmap

从最初接触数学（数与运算）到世界前沿研究方向的**数学知识全景地图**。

- **154 个知识节点**、**256 条依赖边**、**15 个学科大类**
- 按知识深度分 **L0–L6 七个阶段**（不按学期）
- 重点标注 **AI 大模型** 与 **金融量化** 两条垂直路径
- 每个节点包含五要素：所属大类、内容介绍、前置知识、后置方向、具体应用

🌐 **在线访问**：<https://zrx-11.github.io/mathmap/>

## 两个视图

| 视图 | 入口 | 说明 |
| --- | --- | --- |
| 3D 交互全景图 | `index.html` | three.js 正四面体立体图谱。拖动旋转、双指/滚轮缩放、点节点看五要素详情、点前置/后置跳转高亮依赖链；支持按阶段/大类/路径筛选与搜索。三类节点造型：圆球=公共基础、八面体=AI 路径、圆柱=金融量化。 |
| Mermaid 路线版 | `route.html` | 纯流程图，仅含节点与「前置 → 后续」路线，不含说明文字。适合快速建立全局骨架，也可把图复制到 Obsidian / GitHub README / 其他 Mermaid 编辑器里继续编辑。 |

两个视图可互相跳转（页头导航）。

## 文件结构

```
.
├── index.html          # 3D 全景图入口
├── style.css           # 3D 版样式
├── app.js              # 154 节点数据 + 3D 渲染与交互逻辑
├── route.html          # Mermaid 路线版页面
├── math-roadmap.mmd    # 路线图的 Mermaid 源码（154 节点 / 256 边）
├── preview.jpg         # 3D 版预览图
├── lib/
│   ├── three.min.js        # three.js r128（本地）
│   ├── OrbitControls.js    # 轨道控制器（本地）
│   └── mermaid.min.js      # Mermaid 10.9.1（本地）
├── .nojekyll           # 关闭 GitHub Pages 的 Jekyll 处理
└── README.md
```

所有第三方库均已本地化，**不依赖任何外部 CDN，完全可离线运行**。

## 本地打开

直接用浏览器打开 `index.html` 即可；需保持 `index.html`、`style.css`、`app.js`、`lib/` 与 `route.html` 在同一目录（`file://` 协议下可用）。

## 部署 / 更新

仓库已启用 GitHub Pages（Source: `main` 分支 `/` 根目录）。更新内容只需：

```bash
git add .
git commit -m "update"
git push
```

Pages 会自动重新构建，1–2 分钟后生效。

## 数据说明

- 节点间连线表示「前置 → 后续」学习依赖，箭头方向即学习顺序
- 阶段划分：L0 数与运算 → L1 初等数学 → L2 高中阶段 → L3 大学基础 → L4 大学中级 → L5 大学高级 → L6 前沿研究
- 节点内容的掌握标准为建议基准，可按个人目标调整
- 路线版与 3D 版共用同一份数据（154 节点 / 256 边 / 15 大类）
